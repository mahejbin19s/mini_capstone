 🛒 E-Commerce Health Check — Mini Capstone

A data analysis mini-capstone project based on the **Brazilian E-Commerce Public Dataset by Olist**.

This project combines **Python, Pandas, NumPy, SQLite SQL, Exploratory Data Analysis (EDA), and Statistics** to investigate e-commerce orders, sales, customers, products, payments, reviews, and delivery performance.

## 📌 Project Overview

The main objective of this project is to perform an end-to-end analysis of an e-commerce dataset and identify useful business insights.

The analysis covers:

* Data loading and preparation
* Data cleaning
* Revenue and order analysis
* Customer and product analysis
* SQL-based analysis
* Exploratory Data Analysis
* Data visualization
* Statistical analysis
* Business findings and recommendations

## 🎯 Objectives

* Understand the structure of the Olist e-commerce dataset.
* Clean and prepare the data for analysis.
* Use Python with Pandas and NumPy for data processing.
* Store and analyze data using SQLite.
* Write SQL queries to answer business questions.
* Perform Exploratory Data Analysis (EDA).
* Visualize important trends and patterns.
* Apply statistical methods to the data.
* Generate meaningful business insights.

## 📂 Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The dataset contains information related to:

* Orders
* Customers
* Products
* Sellers
* Order items
* Payments
* Reviews
* Geographical information

The dataset is organized into multiple CSV files and is used to perform an integrated e-commerce analysis.

## 📊 Analysis Areas

### 1. Data Preparation

The raw datasets are inspected and prepared for analysis.

This includes:

* Checking data types
* Handling missing values
* Checking duplicate records
* Converting date/time columns
* Preparing datasets for merging
* Creating useful calculated fields

### 2. Python, Pandas & NumPy

Python is used to process and analyze the e-commerce data.

The analysis includes:

* Order calculations
* Revenue calculations
* Customer analysis
* Product analysis
* Review analysis
* Delivery-related calculations
* Aggregation and filtering

### 3. SQLite & SQL

The project uses **SQLite** for database-based analysis.

SQL is used to investigate business questions through operations such as:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `JOIN`
* Aggregation functions

The SQLite database included in the repository is:

```text
olist_capstone.db
```

### 4. Exploratory Data Analysis

EDA is performed to understand patterns and relationships in the data.

Examples include:

* Revenue trends
* Order trends
* Product performance
* Customer behavior
* Review scores
* Delivery performance
* Order-value distribution

### 5. Statistics

Statistical analysis is used to summarize the dataset and support the findings.

The project includes statistical calculations and interpretation of important e-commerce metrics.
